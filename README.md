# 广告数据工作台

Windows 离线 HTML 工具。下载 ZIP、解压，用 Edge 或 Chrome 双击打开“广告数据工作台.html”。不需要安装 Python 或 Excel，无需联网，文件仅在本机浏览器中处理。

## 使用

1. 搜索数据区域拖入或点选一个 ZIP（内含 CSV 分片）或一个 CSV。
2. 对比周期区域选择前一个14天周期的效果 Excel。
3. 现期区域选择后一个14天周期的效果 Excel。
4. 点击“生成 Excel”。当效果表包含多个采销时，弹出复选框：根据搜索商品匹配情况推荐勾选，用户可改选、多选。至少勾选一人。
5. 点击“按所选采销生成”，查看处理提示，再点击“保存 Excel”。文件会保存到浏览器下载目录，或由浏览器询问位置。

三个输入由区域确定用途，不根据文件名猜测顺序。更换文件、重新生成或取消后，旧下载结果会清除。处理过程中可停止。

## SKU → SPU 识别与采销范围

效果表有两组同名“商品ID”“商品名称”时，按用户规定：左侧ID/名称属于SPU，右侧ID/名称属于SKU。通过同名列出现的先后顺序识别，不依赖绝对列号。其他字段均按列名读取，重复商品列不会报错。也支持显式命名的“SPU ID”“SKU ID”。

- 搜索CSV含SPU ID时，直接按SPU汇总。
- 搜索CSV只有“智能投放推广SKU ID”或“SKU ID”时，联合两个效果周期建立SKU→SPU映射，再汇总同一SPU下的搜索记录。
- 全组效果数据先按选中的采销筛选，再按SPU累计指标；搜索中明确属于未选采销的商品会排除并提示。
- 同一SPU下不同SKU正常累加。完全相同的效果明细整行去重；同一SKU的内容不同的记录保留并累加。两个周期分开处理，不跨周期去重。
- 没有映射或映射不唯一的SKU，以“未匹配SKU:编号”单独保留搜索指标，全量/推荐留空，提示中列出编号；不按名称猜测SPU。其归属无法确认，故不按采销过滤。这样数据不会丢失，但不意味着已完整匹配。
- 没有采销列时无需选择；只有一位采销时自动使用；多位时必须通过弹窗确认。推荐选择只作辅助，不等同于自动断定未匹配SKU的归属。

## 周期限制

读取效果表第一张sheet的“时间”，按包含起止日计算天数。两个效果周期须各14天、按前后顺序连续且不重叠；搜索“日期”须覆盖这两个周期（28天）。不符合时强制弹窗并阻止导出，不做天数折算。

本次文件：对比周期2026-10-03至10-16；现期2026-10-17至10-30；搜索覆盖10-03至10-30，全部符合要求。最初13天附件仅经用户授权用于独立计算验证，正式界面始终执行14天校验。

## Excel 输出格式

恰好三个sheet：

1. **广告搜索&推荐数据**：维持手工样例的27列，SPU_ID、商品名称、三级类目，以及搜索/推荐/全量各8项指标（曝光、点击、CTR、CVR、GMV、订单、CPC、ROI）。按搜索曝光降序，保留所选采销全部SPU及未匹配SKU。
2. **广告成交数据（对比周期）**：该文件第二张sheet中所选采销的明细，去除完全相同整行后，保留原列名、原列顺序及左右两组商品列。百分比文本转为Excel百分比数值。
3. **广告成交数据（现期）**：同上。

源效果表原有多少列就保留多少列，本次是40列，旧样例是37列。不会用旧样例固定列位置读取新数据。首张sheet中的ID为文本；A1批注记录周期、采销范围及处理异常。

搜索曝光、点击、GMV、订单、花费来自“展现数、点击数、直接订单金额、直接订单行、花费”。全量对应两个周期所选采销的“展现、点击、成交金额、成交父单量、消耗”相加。推荐=全量−搜索。

CTR=点击/曝光；CVR=订单/点击；CPC=花费/点击；ROI=GMV/花费。先累计再计算，比率保留4位小数，GMV保留2位。分母为零或负数则比率留空，负差额原值保留并提示。效果表成交父单量与搜索直接订单行、消耗与花费可能存在业务口径差异，需要结合源报表解释推荐差额。

## 本次验证

- 两个搜索CSV，共51,212行；搜索曝光345,433，点击24,818，直接成交金额217,372.29，直接订单1,571。
- 全组包含6位采销；可匹配的搜索商品均属于左春泽，界面推荐勾选他。
- 搜索映射为74个SPU，另13个SKU未匹配（曝光2,368）并保留。
- 左春泽输出首张表95行：82个SPU（包括无搜索记录的效果表商品）及13个未匹配SKU；两个效果sheet分别231行和136行，均40列。
- 效果表全组完全重复行分别1,571行、1,389行，已按完整行内容去重。
- Python独立实现逐行核对了输出所有加总指标、派生比率、未匹配记录及两张筛选后的效果表。
- Chromium真实附件测试覆盖：6人复选框、默认推荐、禁止空选、多选、取消、Excel下载、重复列名、拖放及14天拦截。
- 旧附件434,694行的SPU聚合回归通过：152个SPU的四项搜索加总指标仍与手工样例一致。

测试运行于Linux Chromium本机HTTP环境；云浏览器策略禁止file地址，尚未在真实Windows系统上实测双击打开。

## 构建

运行 `python3 build.py` 生成 `dist/广告数据工作台.html`；运行 `python3 package.py` 重新生成下载ZIP。用户运行成品不需要Python。

`core.js` 为解析、映射、筛选、汇总逻辑，`index.template.html` 为界面，`research` 中包含真实附件回归测试和独立验证脚本（运行这些测试需要对应附件）。库随包提供：SheetJS Community Edition 0.18.5（Apache-2.0）、fflate 0.8.2（MIT）。
